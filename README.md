## 🛠️ Tools & Technologies Used

- **HTML5** – Semantic markup for enhanced structure and accessibility
- **CSS3** – Modern styling with Custom Properties (`--variables`)
- **CSS Grid** – Complex multi-column grid positioning and responsive layouts
- **Flexbox** – Internal component alignment and distribution
- **Mobile-First Workflow** – Designed for mobile devices first, then scaled up seamlessly for desktop
